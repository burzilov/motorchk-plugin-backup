# Changelog

## 0.2.0 — 2026-10-27

- Ротация: после новой копии хранятся последние N архивов (по умолчанию 10, `MOTORCHK_BACKUP_KEEP`).
  Удаляются только архивы плагина (`backup-<UTC>-<hex>.zip`) в папке копий.
- Содержимое `cache/` не архивируется (папка сохраняется пустой); `.env` и заявки по-прежнему входят.
- Ошибка удаления архива в админке — общий текст, подробности — в журнал ошибок.
- README: архивы конфиденциальны; описаны состав, кэш и ротация.

## 0.1.1 — 2026-10-22

- Админка резервных копий в общем стиле плагинов.

## 0.1.0 — 2026-10-22

- Полные ZIP-копии сайта без `core/` из админки и CLI: список, скачивание, удаление.
- Хранение вне сайта с правами 0700/0600, проверка согласованности снимка, атомарная публикация архива.
